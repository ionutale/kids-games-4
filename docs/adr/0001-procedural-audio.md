# Procedural WebAudio instead of audio files

Cozy Nook ships with zero audio files: background music and all sound effects are synthesized at runtime with the Web Audio API. The app must be fully offline-capable, licensing-free, and calm-sounding, and no local music/SFX generator exists (qwen3-tts does speech only; dwg-dxf has no audio code; music-sfx-voice-studio is empty). Procedural generation keeps the precache tiny, lets the lullaby loop endlessly without seams, and keeps every sound tunable from code. Alternatives considered: stock loops (Pixabay), Lyria via Gemini API (~$0.04/clip), and existing MP3s from restaurant-manager-game — all rejected as first choice for weight, licensing, or fit; a curated loop can still be swapped in later because game code only calls named scenes/events (`music('home')`, `sfx('correct')`). Voice narration (later milestone) is the sole planned exception and will be generated offline and shipped as files.
